# YouTube Timeline Bookmark & Transcript Search

A Chrome Extension (Manifest V3) to bookmark timeline moments, loop A/B repeat segments, and search transcripts in real time on YouTube.

## Features

- 🔖 **Timeline Bookmarks**: Bookmark any moment with a single click or by pressing **B**.
- 🔁 **A/B Repeat Looping**: Loop video playback continuously between two selected timestamps with a visual range overlay on the player progress bar.
- 🔍 **Real-Time Transcript Search**: Search caption transcripts instantly and jump to exact timestamps.
- 📌 **Progress Bar Tick Marks**: Hover over timeline tick marks to see saved notes and jump to bookmarked moments.
- 📥 **Export to Markdown**: Download timestamped links formatted for easy note-taking and documentation.

## Installation

1. Clone or download this repository.
2. Open Chrome and go to `chrome://extensions`.
3. Enable **Developer mode** (toggle in top-right corner).
4. Click **Load unpacked** and select the project folder.
